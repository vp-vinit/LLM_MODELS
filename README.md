# Cricket Commentary Generator

A cricket commentary generator built using Python, Streamlit, LangChain, and Groq.

## Features
- Enter the match situation.
- Enter the batsman's name.
- Enter the bowler's name.
- Generate short, exciting cricket commentary using AI.

## Installation

Install the required libraries:

pip install -r requirements.txt

## API Key

Create a `.env` file and add your Groq API key:

GROQ_API_KEY=your_groq_api_key

## Run the application

streamlit run cricket_com.py
